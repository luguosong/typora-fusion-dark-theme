# 采用手绘视觉语言,退役玻璃拟态与霓虹发光

## 状态

accepted

## 决定

将 Fusion 主题的共享**基础层**(`fusion-dark/base/`)视觉语言从「玻璃拟态 + 霓虹发光」整体重构为「手绘 / 纸笔速写」风格:**纸面**替代玻璃,**墨色**(`--ink`)描边替代发光,**手绘标记**与**手绘描边**替代规整几何。7 个**主题变体**只定义颜色,故改造基础层一次即得到 7 个手绘配色版。手绘化范围限定在**正文**(`#write`);**外壳**仅少量点睛。

## 背景

早期身份(玻璃 + 霓虹 + 重动效)偏赛博 / 科技感,与团队想要的「手写笔记 / 速写本」气质相悖。手绘语言更贴合 Markdown 写作与 PDF 导出的阅读温度。

## 考虑过的方案

- **选择性点缀**(玻璃主题上零星加手绘):否 —— 手绘与玻璃 / 霓虹同屏严重冲突,四不像。
- **新建独立 `fusion-sketch` 主题**(保留现有 7 主题):否 —— 需长期双维护两套基础层。
- **(采纳)改造共享基础层**:一次改造、7 配色继承;代价是玻璃 / 霓虹身份不可回头(除非 git revert)。

## 结果与影响

- `--glow-*` 霓虹发光变量整体移除;各元素 hover 由「发光 + 放大」改为一次性手绘小动作,不做无限循环抖动。
- 玻璃 / 模糊(`backdrop-filter`)从正文容器移除,改纸面(纯色 + 极淡纸纹)。
- 约束(纯 CSS、零 JS):手绘标记用 `mask` + `background-color: var()`;手绘描边用 `border-image` / `-webkit-mask-box-image`;强抖动用 `feTurbulence` + `feDisplacementMap` 滤镜,且**只能作用于纯边框伪元素层**——套在含文字元素上会扭曲文字。
- 落地基线为 master 的 `fusion-dark/base/` 拆分结构(词汇表 CONTEXT.md 同步维护)。
