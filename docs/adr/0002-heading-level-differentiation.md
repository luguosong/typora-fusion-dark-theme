# 标题层级差异化:两色调渐变 + 逐级不同的手绘装饰

## 状态

accepted

## 决定

让 H1–H6 六级标题**一眼可辨**,不再仅靠字号,而是叠加三个正交维度区分:

1. **字号阶梯**:H2–H6 依次为正文的 1.55 / 1.35 / 1.18 / 1.08 / 1 倍,字重统一 500。H5/H6 不小于正文,在连续读写时保持清晰。
2. **两色调渐变**:H2/H3 用主色;H4/H5 经 `color-mix()` 从主色向正文色逐级渐淡;H6 用正文次要色。颜色本身编码「深度」。
3. **每级不同的手绘装饰形状**:H2 整宽波浪下划线、H3 左侧竖条笔刷、H4 直线下划线、H5 点线下划线、H6 无装饰(正文字号大写标签体)。

颜色渐变用 `color-mix()` 从既有 `--primary-color`/`--text-color` 派生,**不新增每主题变量**。

## 背景

原实现里 H2–H6 **颜色全同**(都是主色)、**装饰全同**(同一条波浪下划线,仅宽度 100%→40% 递减)、**字重全同**(浏览器默认粗体),且 H4/H5/H6 字号仅差 0.05rem。结果六级几乎不可区分——这是「配色角色」内部的**层级碰撞**(区别于 CONTEXT.md 里不同角色撞同一色的「角色碰撞」)。用户诉求正是「正文能清晰区分二级、三级等不同标题」。

## 考虑过的方案

- **单色 + 仅拉大字号/字重**:否 —— 六级都要区分时字号跨度不够,H5/H6 仍会挤在正文附近。
- **多色(每级一色 / 彩虹)**:否 —— 破坏品牌单色识别,视觉花乱。
- **前导编号式 / 前导标记装饰**(在文字最前面加涂鸦标记):否 —— 落在「文字前导位」,会与笔记**手动序号**(如「1.1」)视觉冲突。故 H3–H5 的装饰一律避开前导位:H3 竖条移到左侧 gutter,H4/H5 移到文字下方。
- **(采纳)两色调渐变 + 逐级不同装饰(避开前导位) + 字号阶梯**。

## 结果与影响

- **共享标题规则**:颜色用 `color-mix()` 派生,字号随正文基准变化,4 套主题自动适配;手绘图元 `--sketch-line` / `--sketch-dots` / `--sketch-brush` 定义在 `foundation.css`(base 结构常量,随主题变色)。
- **兼容手动序号**:延续「不自动编号」原则,且所有装饰都不占前导位,笔记自带的「1.1.1」不受影响。
- **伪元素分配**:装饰统一走 `::after`(H2/H4/H5 下划线、H3 左侧竖条);`::before` 留给 Typora 内置标题标签,避免冲突。编辑模式(`.md-focus`)隐藏装饰。
- **中文注意**:H6 的 `text-transform: uppercase` 仅对英文生效;中文 H6 靠小字号 + 字间距 + 色差区分。
- H1 保持居中,字号为正文的 1.8 倍。

## 变更

- **2026-10-19**: 在既有标题全 500 的约定上,将字号改为相对正文的比例,H5/H6 不再低于正文。保留各级手绘形状、编辑时隐藏装饰与不自动编号的原则;目录同样仅呈现标题原文,避免与手动序号重复。
